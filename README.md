# Personal Finance Tracker 💰

A web application built with R and Shiny
for tracking personal income and expenses.

## Features
- Dashboard with key financial metrics
- Add, Edit, Delete income and expenses
- Data Visualizations (Bar, Pie charts)
- Statistical Analysis
- Correlation Analysis
- Persistent CSV storage

## Technologies
- R Programming
- Shiny
- shinydashboard
- Base R plotting
